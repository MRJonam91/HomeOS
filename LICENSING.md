## 🇮🇹 Perché questa scelta
- **AGPL-3.0**: protegge la sovranità dei dati della casa. Chiunque modifichi o integri HomeOS per erogarlo come servizio web o cloud proprietario deve rilasciare il codice sorgente migliorato alla comunità.
- **Licenza commerciale**: consente ad aziende prop-tech, costruttori, installatori e facility manager di integrare HomeOS in soluzioni commerciali o appliance proprietarie senza vincoli di copyleft.
- **CLA**: essenziale affinché l'autore originale possa offrire la licenza commerciale e preservare la possibilità di una cessione strategica (full IP buyout).
- **Header SPDX**: ogni file sorgente include l'header SPDX con autore e anno di rilascio.

## 🇬🇧 Why this choice
- **AGPL-3.0**: safeguards personal home data sovereignty. Anyone modifying or extending HomeOS as a web or cloud service must contribute improvements back to the community under equal terms.
- **Commercial license**: enables prop-tech firms, builders, installers, and facility management providers to embed HomeOS in turnkey appliances or proprietary platforms without copyleft constraints.
- **CLA**: critical so the author can grant commercial exceptions and preserve full intellectual property transferability.
- **SPDX headers**: each source file includes a standard SPDX identifier with copyright declaration.
